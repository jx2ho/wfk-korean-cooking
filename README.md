# 다낭 한국 요리 문화수업 모바일 가이드

라볶이와 화채를 만드는 과정을 스마트폰에서 한 단계씩 확인하는 정적 웹앱입니다.

## 로컬 실행

파일을 직접 열면 기본 화면은 볼 수 있지만, 오프라인 캐시 기능까지 확인하려면 로컬 서버로 실행하세요.

```powershell
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`으로 접속합니다.

## 배포

별도 빌드 과정이 없습니다. 이 폴더 전체를 GitHub 저장소에 올린 뒤 Netlify에서 저장소를 연결하면 됩니다. Publish directory는 `.`으로 설정합니다.

## 이미지 순서

- `step-1.webp`: 떡 불리기
- `step-2.webp`: 과일·어묵 썰기
- `step-3.webp`: 라볶이 끓이기
- `step-4.webp`: 화채 만들기
- `step-5.webp`: 라면사리 넣기
- `step-6.webp`: 표지 및 완성 화면
